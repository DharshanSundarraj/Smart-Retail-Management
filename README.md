# Smart Retail Management System

---

### Project Overview
This repository contains the core backend application for a cloud-based Retail Management System tailored for enterprise supermarket operations. Developed by the Java Full Stack Developers Team (Team 1), this application is engineered to handle transactional processing and serve as the central backend integration point for AWS cloud infrastructure and data analytics pipelines.

---

### System Architecture & Scope

| Category | Components |
| :--- | :--- |
| **Sales & Operations** | POS Billing, Payments, GST, Discount |
| **Entity Management** | Customers, Suppliers, Employee, Role Management |
| **Supply Chain** | Inventory, Purchase Management |
| **Security & Auditing**| Authentication, JWT, Reports, Notifications, Audit Logs |

---

### Technology Stack

| Domain | Technologies |
| :--- | :--- |
| **Core Framework** | Java 21, Spring Boot, Spring Security |
| **Data Persistence** | Spring Data JPA, Hibernate, MySQL/PostgreSQL |
| **Performance** | Redis Cache |
| **API Ecosystem** | REST API, Swagger |
| **Development Tools**| Maven, Git, JUnit |
